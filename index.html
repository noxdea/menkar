Decode with evidence.

Menkar treats detection as evidence, not save policy. Applications stay in control while strict conversion protects the original document.

Broad detection

UTF-8 plus seven Japanese, Chinese, Korean, and Western legacy encodings.

Reversible edits

Round-trip checks expose characters that cannot be written back without silent data loss.

Bounded work

Sampling keeps memory and runtime predictable, even when source files are large.

Read unknown text.

Detect first, decode strictly, then decide how your application saves.
